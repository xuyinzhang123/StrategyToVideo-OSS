# 实证：9:25 竞价跳空过滤对「尾盘金叉买 / 次日开盘卖」的影响

- 标的：海得控制（002184，深主板）
- 展示区间：2021-11-19 ~ 2026-11-19（近五年），前置数据仅用于指标预热
- 数据源：东方财富公开日线接口，`klt=101`、`fqt=0`（未复权），取数日 2026-11-20，已剔除当日未收盘 K 线；共 1417 根（2021-01-04 ~ 2026-11-19）
- 口径：初始资金 100,000 元，每手 100 股，`dividendPolicy=ignored`（不含现金分红；除权缺口按普通下跌处理）
- 策略：MACD(12,26,9) 金叉当日收盘买入、次一交易日开盘卖出；竞价过滤开启时，持仓期每个交易日 9:25 按 `开盘价 / 前收 - 1` 判断，跳空 ≥ 阈值则当日开盘不卖、继续持有，否则开盘卖出
- 复现：样例卡 [`samples/strategy_cards/close_buy_open_sell_002184.json`](../../samples/strategy_cards/close_buy_open_sell_002184.json)

## 结论（先看这个）

**在本标的、本区间上，竞价跳空过滤没有提升策略，反而稳定地拖累结果。** 不启用过滤时期末资产 117,399.02 元（+17.40%，最大回撤 10.12%）；启用任意正阈值后，期末资产全部低于无过滤档，多数档位转为亏损。这与「高开说明情绪强、应继续持有」的直觉相反。

对比同期长期持有基准（期末 69,742.99 元，约 -30.3%）：无过滤策略跑赢基准约 47.7 个百分点；叠加过滤后优势大幅缩水，1% 阈值档甚至低于基准。**该结论只对这一标的、这一区间、这一口径成立，不外推到其它股票或时段。**

## 为什么会拖累

对 0.5% 阈值档的 13 次 HOLD 逐笔诊断：

- 触发 HOLD 时放弃的当日开盘跳空平均为 **+3.65%**——也就是说，策略在平均已有 3.65% 高开的时候，主动放弃了以该价格卖出。
- 其中 **8 次**后续实际成交价低于被放弃的开盘价，仅 5 次更高。
- 机制：本策略的卖出价就是次日开盘价，高开本身即是卖出的收益来源。竞价过滤在跳空偏强时禁止卖出，等于把已经兑现的高开收益重新暴露给后续交易日波动；次日若跳空回落，只能以更低价格卖出。
- 胜率佐证：无过滤 32.7% → 0.5% 阈值 25.5%；0.1%/0.2% 阈值因过滤过于频繁（27/26 次）降至 16.4%。

这是引擎按既定规则执行的**真实结果**，不是实现缺陷：HOLD 仅当日不卖、次交易日重新评估，峰值只取已收盘价，无未来函数。

## 解读边界

1. 结论与「竞价过滤在浦发银行样例上有效」并不矛盾——样例区间最大跳空仅 0.30%，2% 阈值从未触发；本标的近五年最大跳空达 10.04%，过滤频繁触发，二者样本条件完全不同。
2. 未计现金分红（`dividendPolicy=ignored`）。若计入分红，各档期末资产会整体变化，但「过滤档系统性低于无过滤档」的相对关系来自卖出时机，不依赖分红处理。
3. 未计涨跌停无法成交的极端情形之外的滑点、冲击成本；未做参数寻优的样本外检验，表中阈值不应被当作「最优参数」。
4. 这是流程演示与可复现性验证，不是投资建议；回测金额是本地模拟结果。

## 复现步骤

1. 按 README 安装依赖并启动本地网页（`npm start`，打开 `127.0.0.1:8080`）。
2. 选择「策略回测视频（自动取数）」，证券代码填 `002184`，区间填 `2021-11-19` 至 `2026-11-19`，模板选「尾盘买入·次日开盘卖出」，入场信号选 `macd_golden`。
3. 如需复现过滤档，在同一表单把「开盘跳空阈值」设为对应百分比（0.1~5）；不填即无过滤。
4. 创建任务并确认执行；完成后查看结果摘要（收益、最大回撤、成交笔数）与逐行溯源。
5. 离线精确对拍可直接用引擎：`runStrategy(card, input)`，卡文件即上述样例卡；确定性由同一输入下 `reproducibility.resultSha256` 一致保证。
